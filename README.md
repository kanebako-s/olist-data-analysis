# olist-data-analysis

## プロジェクト概要。
Kaggleが公開しているデータセット「Brazilian E-Commerce Public Dataset by Olist」の分析して、売り上げ向上に繋がる提案をすることが目的です。


## 現在の進捗。
* 満足度スコアを１にした顧客の離脱率が９７％を超えている事が確認できた。
* 各地域で配達予定日より平均１０日程度早く配達されていること分かる。このことから予定配達日の設定は当てにならないものであり、顧客の信頼性を損なう一因になっているものと予想される。
* 特定の地域に、満足度の低い顧客が偏っていることは確認できなかった。
* 予定より早期に配達されてもスコアが１になっている件は、不満の原因が「配達」ではなく「商品の状態」にある可能性が高い。
