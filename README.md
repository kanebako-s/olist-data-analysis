# タイトル
**ブラジル最大のEC「Olist」のリピート率改善に向けた物流SLAの最適化と機会損失の可視化。**


## プロジェクト概要。
Kaggleで提供されているOlistの公開データセットを用いて、プラットフォームの運用上の問題である「低リピート率」の原因を特定。
物流品質（リードタイム）と顧客満足度の相関を分析し、悪質セラーによる経済的損失を数値で可視化しました。


## 背景
Olist全体のリピート率は約3%と極めて低く、１注文当たりの平均額が約161レアル（約五千円）であることから、新規顧客の獲得コスト（CAC)を回収しにくい構造になっていた。
したがって顧客体験を毀損している原因を明らかにしリピート率の改善を図る必要があった。

結論 : 満足度スコア1をつけた顧客の多くが配送品質に不満を持っていた。
